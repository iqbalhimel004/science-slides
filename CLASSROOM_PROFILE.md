Version: 1.0
Last revised: 2026-09-05

This file records classroom facts that materially affect timing, rendering and fallback design. Unknown fields must not be guessed.

## Confirmed project requirement

- Default lesson/deck target: one **60-minute** class.
- All expected classroom actions must fit inside those 60 minutes.
- Planned sequence should normally occupy 50–55 minutes, leaving 5–10 minutes of unallocated contingency.

## Timing structure

For a 60-minute class:

- CORE target: 40–45 min
- FLEX target: 5–10 min
- CORE + FLEX target: 50–55 min
- contingency: 5–10 min
- STRETCH: appendix/enrichment only; not counted in the planned core lesson

CORE includes the retrieval opener, essential explanation, required example/visual, at least one understanding check, essential practice and exit check.

FLEX may include a second example, extra practice, optional discussion or enrichment that can be skipped without breaking the lesson.

If the user's actual period differs from 60 minutes, update this profile and re-budget before rendering decks for that setting.
