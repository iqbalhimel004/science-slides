## Canonical production architecture

**Scientific truth -> structured specification -> R1/R2/R3 routing -> specialized visual/media route -> controlled PptxGenJS assembly -> automated QA -> semantic science QA -> direct pixel QA -> compatibility/export/offline QA -> user acceptance -> GitHub checkpoint.**

Key principles:

- NCTB controls syllabus/exam scope, not automatic scientific truth;
- no-reset migration preserves valid prior work;
- R3 science-critical geometry/topology is controlled/deterministic and semantically tested;
- authoritative real/scientific imagery is preferred before custom AI generation when suitable;
- PptxGenJS is primary controlled assembly, not the only scientific asset engine;
- Canva is optional finishing/context support, not science authority;
- safety, quantitative integrity, source freshness, model limits and accessibility are explicit gates;
- user review occurs after internal QA;
- repeated micro-patching triggers clean rebuild/route change;
- selective revalidation avoids unnecessary full re-audits;
- final PowerPoint/PDF/offline behavior is verified separately.
