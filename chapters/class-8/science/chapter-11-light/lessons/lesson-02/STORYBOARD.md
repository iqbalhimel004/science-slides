## Storyboard principles for this lesson

- reuse Lesson 1 ray/normal vocabulary instead of reteaching it;
- apparent position must be shown with real rays plus dashed backward extensions;
- applications move from familiar/concrete to more abstract;
- mirage must use temperature/refractive-index gradient reasoning, not a single hard mirror-like air boundary;
- critical angle must be introduced as the exact threshold `r = 90°`, not as TIR itself;
- TIR requires both conditions: higher-index→lower-index direction and `i > C`;
- optical fibre follows immediately as an application of TIR;
- no numerical Snell-law or critical-angle calculations in CORE;
- no CORE slide depends on internet access.

### L2-S07 — মরীচিকা: পানি নয়, বায়ুর স্তরে আলোর পথ বদলায়

- Segment: CORE
- Purpose: correct the common hard-boundary/TIR oversimplification and explain mirage qualitatively.
- Core content:
  - hot ground heats the air nearest the surface;
  - temperature changes with height, so refractive index changes gradually through the air;
  - light from the sky/distant object bends progressively through this gradient and can curve upward into the observer's eye;
  - the eye extrapolates the ray backward and perceives an apparent image near/below the road;
  - `ওখানে বাস্তব পানি নেই।`
- Slide family/layout intent: full-width road/air-gradient ray diagram.
- Visual/resource: R2-02.
- Visual purpose: Explain / Sequence
- Teacher note: if discussing textbook TIR phrasing, explicitly say the real atmosphere is a gradient rather than one sharp mirror-like interface. No gradient-index mathematics.
- Student action/question: `এখানে কোন জিনিসটি বাস্তবে নেই—পানি, আলো, নাকি গরম বায়ু?`
- Expected response: পানি.
- Segment-response role: misconception refutation
- Estimated time: 4 min
- Source reference(s): NCTB printed p.112 / PDF p.117; C11-008; B11-013; SI-11-005; S20.
- Static/offline fallback: static gradient diagram.
- Transition to next slide: `এবার denser → rarer ray-এর angle বাড়াতে থাকলে কী ঘটে দেখি।`

### L2-S08 — Incidence angle বাড়ালে refracted ray কোথায় যায়?

- Segment: CORE
- Purpose: build the critical-angle concept from a progression rather than dropping in a definition.
- Core content:
  - light travels from higher-index/optically denser medium to lower-index/rarer medium;
  - as `i` increases, refracted angle `r` also increases;
  - refracted ray moves farther away from the normal and approaches the interface.
- Slide family/layout intent: three progressive ray states with same media/boundary.
- Visual/resource: R2-03 stage 1.
- Visual purpose: Sequence / Predict
- Teacher note: keep reflected ray secondary; focus attention on refracted ray progression.
- Student action/question: predict what happens to `r` as `i` increases.
- Expected response: `r` increases / ray moves farther from normal.
- Segment-response role: predict
- Estimated time: 4 min
- Source reference(s): NCTB printed p.112; S4.
- Static/offline fallback: three static panels.
- Transition to next slide: `একটি বিশেষ angle-এ refracted ray ঠিক surface বরাবর চলে।`

### L2-S09 — সংকট কোণ: যখন r = 90°

- Segment: CORE
- Purpose: define critical angle precisely and distinguish it from TIR.
- Core content:
  - critical angle `C`: higher-index/denser medium-এ এমন incidence angle যার জন্য lower-index medium-এ refracted angle `r = 90°`;
  - refracted ray then travels along the interface;
  - **critical angle-এ এখনো TIR হয়নি।**
- Slide family/layout intent: single dominant ray diagram + definition strip.
- Visual/resource: R2-03 stage 2.
- Visual purpose: Explain / Locate
- Teacher note: repeatedly point to which angle is `C` and which is `90°`; both are measured from their normals as appropriate.
- Student action/question: `Critical angle-এ refracted ray কোথায় যায়?`
- Expected response: interface বরাবর; `r = 90°`.
- Segment-response role: hinge
- Estimated time: 4 min
- Source reference(s): NCTB printed p.112 / PDF p.117; C11-009; S4.
- Static/offline fallback: static labelled diagram.
- Transition to next slide: `তাহলে C-এর চেয়ে angle আরেকটু বাড়ালে?`

### L2-S10 — পূর্ণ অভ্যন্তরীণ প্রতিফলন: দুইটি শর্ত একসাথে

- Segment: CORE
- Purpose: state TIR correctly and prevent the `denser→rarer always TIR` misconception.
- Core content:
  - Condition 1: light travels from higher-index/optically denser medium toward lower-index/rarer medium;
  - Condition 2: incidence angle `i > C`;
  - then the ideal ray is reflected back into the first medium: total internal reflection.
- Slide family/layout intent: two-condition checklist + ray diagram.
- Visual/resource: R2-03 stage 3.
- Visual purpose: Explain / Compare
- Teacher note: do not imply TIR at `i = C`; that is the threshold case.
- Student action/question: `শুধু denser → rarer হলেই কি TIR হবে?`
- Expected response: না; `i > C`-ও লাগবে.
- Segment-response role: misconception refutation / hinge
- Estimated time: 4 min
- Source reference(s): NCTB printed pp.112–113 / PDF pp.117–118; C11-010; S4.
- Static/offline fallback: static two-condition slide.
- Transition to next slide: `তিনটি case একসাথে দেখে দ্রুত classify করি।`

### L2-S11 — i < C, i = C, i > C — কোনটি কী?

- Segment: CORE
- Purpose: consolidate critical-angle/TIR distinction with a high-value hinge.
- Core content:
  - Case A: `i < C` → refraction into second medium;
  - Case B: `i = C` → refracted ray along interface, `r = 90°`;
  - Case C: `i > C` → TIR.
- Slide family/layout intent: three equally sized panels; answers initially hidden if reveal is reliable.
- Visual/resource: R2-03 full sequence.
- Visual purpose: Compare / Practice / Predict
- Teacher note: ask students to classify before revealing labels.
- Student action/question: classify A/B/C and justify one of them in one sentence.
- Expected response: correct three-way classification; TIR only in C.
- Segment-response role: hinge / practice
- Estimated time: 3 min
- Source reference(s): S4; C11-009/C11-010.
- Static/offline fallback: question-state and answer-state static copies.
- Transition to next slide: `এই repeated TIR দিয়েই optical fibre আলোকে পথ দেখায়।`

### L2-S12 — Optical fibre: আলোকে ভেতরে রেখে এগিয়ে নেয় কীভাবে?

- Segment: CORE
- Purpose: explain optical-fibre working directly from TIR.
- Core content:
  - light enters a thin transparent guiding region;
  - at suitable internal incidence angles, repeated TIR keeps the ray guided along the fibre, even through gentle bends;
  - optional small current-science note: real fibres commonly use a higher-index core with lower-index cladding to support guidance;
  - fibre does **not** store light.
- Slide family/layout intent: long curved fibre cutaway with one tracked ray.
- Visual/resource: R2-04.
- Visual purpose: Explain / Sequence
- Teacher note: core/cladding is supplementary, non-assessed; do not turn this into telecom engineering.
- Student action/question: `Ray বারবার fibre-এর ভেতরে থাকে কোন phenomenon-এর জন্য?`
- Expected response: total internal reflection.
- Segment-response role: explain / retrieval
- Estimated time: 4 min
- Source reference(s): NCTB printed p.113 / PDF p.118; C11-011; S4.
- Static/offline fallback: static cutaway.
- Transition to next slide: `এই guided light বাস্তবে কোথায় কাজে লাগে?`
