## Storyboard principles for this lesson

- introduce only the lens concepts required by magnifier, eye and spectacles;
- distinguish converging vs diverging action qualitatively; no lens formula or power calculation;
- image vocabulary is functional, not a full geometrical-optics unit;
- magnifying-glass explanation must explicitly place the object inside the focal length;
- teach the eye by functional groups rather than isolated label memorization;
- cornea + crystalline lens are the focusing system; cornea performs most initial bending, lens fine-tunes through accommodation;
- pupil is an opening in the iris, not a black solid structure;
- spectacles content is clearly labelled supplementary because NCTB lists the outcome but omits the explanatory body section;
- all CORE content must work offline.

### L3-S06 — Magnifying Glass: object focal length-এর ভেতরে

- Segment: CORE

- Core content:

  - outgoing rays diverge; their backward extensions meet on the object side;
  - image is virtual, erect and enlarged;
  - concise statement: `Magnifying glass কাজ করে কারণ object-টি focal length-এর ভেতরে রাখা হয়।`
- Slide family/layout intent: progressive two-ray construction + final image label.
- Visual/resource: R3-03.
- Visual purpose: Sequence / Explain
- Teacher note: do not claim a convex lens always magnifies; object position controls image type.
- Student action/question: choose from `real/virtual`, `erect/inverted`, `magnified/reduced`.
- Expected response: virtual, erect, magnified.
- Segment-response role: explain / hinge
- Estimated time: 5 min
- Source reference(s): NCTB printed p.113 / PDF p.118; C11-012; S7/S8.
- Static/offline fallback: staged static ray diagrams.

### L3-S09 — Cornea, Iris, Pupil: light entry ও control

- Segment: CORE
- Purpose: explain the eye's front optical/light-control structures and correct two common misconceptions.
- Core content:
  - cornea: transparent front surface; performs most of the eye's initial refraction/focusing;
  - iris: colored muscular structure regulating pupil size;
  - pupil: **opening** in the iris through which light enters;
  - guardrails:
    - `pupil কোনো কালো কঠিন বস্তু নয়`;
    - `crystalline lens একাই সব focusing করে না`.
- Slide family/layout intent: zoomed front-eye cutaway + two callouts.
- Visual/resource: R3-04 stage 2.
- Visual purpose: Locate / Explain / Misconception correction
- Teacher note: avoid numerical diopter values; only functional hierarchy matters.
- Student action/question: `pupil নিজে কি একটি solid structure?` and `cornea-এর optical role কী?`
- Expected response: no; pupil is an opening. Cornea provides major initial bending.
- Segment-response role: hinge / misconception refutation
- Estimated time: 4 min
- Source reference(s): NCTB p.114; S16/S17; SI-11-006; B11-017.
- Static/offline fallback: static zoom.
- Transition to next slide: `তাহলে কাছের-দূরের বস্তুতে fine focus কীভাবে বদলায়?`

### L3-S10 — Accommodation: lens-এর shape বদলে fine focus

- Expected response: shape/optical power changes.
- Segment-response role: hinge
- Estimated time: 4 min
- Source reference(s): S17; B11-018; SI-11-006/SI-11-007.
- Static/offline fallback: static two-state comparison.

### L3-S12 — চশমা কীভাবে সাহায্য করে? — Supplementary source-gap repair

- Core content:

- Student action/question: `Myopia-তে diverging না converging lens?`

- Segment-response role: explain / retrieval
- Estimated time: 4 min
- Source reference(s): NCTB outcome p.108 / PDF p.113; C11-021; SI-11-001; S10/S18; B11-015/B11-019.
- Static/offline fallback: static pair.
- Transition to next slide: `শেষে lens → magnifier → eye → spectacles chain মিলিয়ে দেখি।`
