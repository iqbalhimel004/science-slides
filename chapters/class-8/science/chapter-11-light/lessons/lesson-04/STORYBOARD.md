## CORE slides

### L4-S01 — Retrieval: camera-তে কোন image দরকার?

- Time: 3 min
- Ask: screen/film/sensor plane-এ ধরতে image real না virtual? erect না inverted?
- Expected: real, inverted.
- Purpose: bridge from Lesson 3.

### L4-S02 — Photographic camera: প্রধান অংশ

- Time: 4 min
- Show: lens system, aperture/diaphragm, shutter, light-tight body, film/plate image plane.
- Explicit label: `Textbook photographic/film-camera model`.
- Visual: R4-01.

### L4-S03 — Object → lens → image plane

- Time: 3 min
- Trace incoming light through lens to receiving plane.
- Keep aperture/shutter detail for later.
- Visual: R4-01 + R4-02 overlay.

### L4-S04 — Camera image: real, inverted

- Time: 3 min
- Simplified converging-lens ray construction.
- Actual rays converge at image plane; image is real and inverted.
- Do not imply one fixed image size.
- Visual: R4-02.

### L4-S05 — Aperture / diaphragm: opening size

- Time: 3 min
- Larger aperture → more light admitted in the same time; smaller → less.
- No f-number mathematics.
- Aperture does not by itself set exposure duration.
- Visual: R4-03 stage 1.

### L4-S06 — Shutter + exposure: কতক্ষণ light পৌঁছাবে?

- Time: 3 min
- Shutter controls the time interval the recording plane receives light.
- Contrast: aperture = opening size; shutter = time.
- Visual: R4-03 stage 2.

### L4-S07 — Film chemistry + one-line digital contrast

- Time: 5 min
- Visible banner: `Film camera chemistry — modern digital cameras do not use this process`.
- Four-step simplified black-and-white sequence:
  1. exposure creates latent image pattern in silver-halide material;
  2. developer reduces exposed grains to metallic silver;
  3. fixer/hypo removes remaining undeveloped/unexposed silver halide;
  4. remaining silver pattern forms a negative.
- Gate-B compression: **no dedicated CORE digital-camera slide**.
- One-sentence contrast only: `Digital cameras record light electronically on image-sensor pixels; they do not use developer/hypo film processing.`
- Detailed CCD/CMOS/sensor architecture = STRETCH only.
- Visual: R4-04 with small digital callout.
- Sources: S14/S15 + S19.

### L4-S08 — Eye vs Camera: shared functions

- Time: 3 min
- Camera lens system ↔ cornea + crystalline lens focusing system.
- Aperture/diaphragm ↔ iris/pupil light-control system.
- Film/sensor plane ↔ retina as receiving surface.
- Banner: `Similar function ≠ identical structure`.
- Visual: R4-05 stage 1.

### L4-S09 — Same function, different focusing mechanism

- Time: 3 min
- Eye: retina distance essentially fixed; accommodation changes crystalline-lens shape/optical power; cornea does most initial bending.
- Conventional camera example: focusing may involve moving lens/lens-group relative to image plane.
- Do not universalize one mechanism to all modern cameras.
- Visual: R4-05 stage 2.

### L4-S10 — Analogy limits

- Time: 2 min
- Eyelid is not an exact optical shutter equivalent.
- Retina receives light/starts biological visual processing; it does not store a photographic negative like film.
- Shared function ≠ same mechanism/material.
- Visual: R4-05 stage 3.

### L4-S11 — Guided application

- Time: 4 min
- Projector-safe camera/eye component-function question.
- Students match functions and identify one analogy limit.
- Optional: identify where a real/inverted camera image forms.
- Visual: R4-07.
- Final geometry/labels must be checked against visible NCTB exercise pages before freeze.

### L4-S12 — Integrated chapter map + final exit

- Time: 6 min
- Gate-B change: concept map and exit check are merged into one closing slide/sequence.
- Concept chain:
  `Light/seeing → refraction → apparent position → critical angle/TIR → optical fibre → lens/image → magnifier → eye → spectacles supplement → camera → eye-camera comparison`
- Ask students to explain one arrow in the chain.
- Final four questions:
  1. `Camera image real না virtual?`
  2. `Aperture আর shutter-এর কাজ কীভাবে আলাদা?`
  3. `Eye accommodation আর camera focusing কি identical mechanism?`
  4. `Developer + hypo film camera না digital camera context?`
- Visual: R4-06 integrated with exit prompts.
